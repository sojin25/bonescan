# 画像分析スクリプト

[English](./README.md) | [日本語](./README_JA.md)

このプロジェクトは、2つの画像を比較し、特定の色領域（赤と青）の類似度を分析するPythonスクリプトです。Jupyter Notebook環境で実行できるように設計されています。

## 機能

- 輪郭に基づく画像のアライメント
- 赤と青の色領域のセグメンテーション
- Dice係数とHausdorff距離による類似度の計算
- 一致・不一致領域を視覚化したオーバーレイ画像の生成

## 必要条件

- Python 3.6以上
- Jupyter Notebook

## 必要なPythonモジュール

以下のPythonモジュールが必要です：

- opencv-python (cv2)
- numpy
- scikit-image
- scipy
- matplotlib

これらのモジュールは以下のコマンドでインストールできます：

```
pip install opencv-python numpy scikit-image scipy matplotlib
```

## 使用方法

1. このリポジトリをクローンまたはダウンロードします。

2. 比較したい2つの画像ファイルを用意し、スクリプトと同じディレクトリに配置します。
   - デフォルトのファイル名:
     - `0130000001-1_origin_output.png`
     - `0130000001-1_filter_output.png`
   - 別の画像を使用する場合は、スクリプト内の`img1_path`と`img2_path`変数を適宜変更してください。

3. Jupyter Notebookを起動します：
   ```
   jupyter notebook
   ```

4. 新しいノートブックを作成し、提供されたスクリプトの内容をセルにコピー＆ペーストします。

5. セルを実行します。結果として、以下が表示されます：
   - 赤と青の領域それぞれのDice係数
   - 赤と青の領域それぞれのHausdorff距離
   - 一致・不一致を示すオーバーレイ画像

## カスタマイズ

- 色範囲の調整: `lower_red1`, `upper_red1`, `lower_red2`, `upper_red2`, `lower_blue`, `upper_blue`変数を調整することで、検出する色範囲を変更できます。
- オーバーレイの透明度: `create_overlay_image_with_white_background`関数の`alpha`パラメータを変更することで、オーバーレイ画像の透明度を調整できます。

## 注意事項

- 画像のサイズや形式によっては、アライメントやセグメンテーションの結果が異なる場合があります。
- 大きなサイズの画像を処理する場合、実行に時間がかかる可能性があります。

# 類似度の計算方法

このスクリプトでは、2つの主要な指標を使用して画像の類似度を計算しています：

### Dice係数

Dice係数は、2つのサンプルセット間の重複の度合いを測定する統計指標です。画像分析の文脈では、2つの領域（セグメント）の類似性を測定するために使用されます。

- 計算式：Dice = (2 * |X ∩ Y|) / (|X| + |Y|)
  - Xと Yは比較する2つのセット（この場合、画像の特定の色領域）
  - |X ∩ Y| は2つのセットの共通要素の数
  - |X| と |Y| はそれぞれのセットの要素数

- 値の範囲：0 から 1
  - 1 に近いほど、2つの領域が非常に類似していることを示します
  - 0 に近いほど、2つの領域が全く異なることを示します

### Hausdorff距離

Hausdorff距離は、2つの点集合間の類似性を測定する指標です。画像分析では、2つの形状や輪郭の違いを定量化するのに使用されます。

- 計算方法：
  1. セットA内の各点から、セットB内の最も近い点までの距離を計算
  2. セットB内の各点から、セットA内の最も近い点までの距離を計算
  3. 上記の全ての距離の中で最大のものをHausdorff距離とする

- 特徴：
  - 2つの形状の全体的な類似性を1つの数値で表現
  - 小さい値ほど2つの形状が類似していることを示す
  - アウトライヤー（外れ値）に敏感

これらの指標を組み合わせることで、色領域の重なり（Dice係数）と形状の類似性（Hausdorff距離）の両方の観点から、画像の類似度を総合的に評価することができます。
